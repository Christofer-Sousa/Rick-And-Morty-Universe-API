# 🛸 Rick and Morty Universe

Uma aplicação web para explorar personagens do universo de Rick and Morty.

Projeto desenvolvido para praticar consumo de API, manipulação do DOM, eventos e construção de interfaces responsivas com HTML, Tailwind CSS e JavaScript.

## 🚀 Funcionalidades

- 🔎 Busca por personagem
- 🟢 Filtro por status
- 📄 Paginação
- ⏳ Loading state
- ⚠️ Error state
- 🔍 Empty state
- 📱 Layout responsivo
- 🌀 Consumo da Rick and Morty API

## 🛠️ Tecnologias

- HTML5
- Tailwind CSS
- JavaScript
- Rick and Morty API

## 🎯 Objetivo

Projeto desenvolvido como prática de Frontend, com foco em:

- Consumo de APIs
- Fetch e requisições HTTP
- URLSearchParams
- Eventos e debounce
- Manipulação do DOM
- Responsividade
- Organização de código

## 📌 Próximos passos

Possíveis funcionalidades futuras:

- Favoritos com LocalStorage
- Página de detalhes do personagem
- Personagem aleatório
- Animações e microinterações
